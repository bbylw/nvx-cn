## 安全

Microsoft 高度重视我们软件产品和服务的安全，这涵盖我们在 GitHub 组织中的所有源代码仓库。

**请不要通过公开的 GitHub issue 报告安全漏洞。**

有关安全报告的信息、地点、联系方式和相关政策，请参阅 Microsoft 仓库的最新指南：
[https://aka.ms/SECURITY.md](https://aka.ms/SECURITY.md)。
