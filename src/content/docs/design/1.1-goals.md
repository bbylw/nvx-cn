[1. 架构总览](/docs/design/1-architecture-overview/)

本架构具有以下目标：

- 在 Linux 宿主和 Windows 宿主上启动同一个未压缩的 Linux 直接启动内核。
- 使客户机可见的机器独立于所选的 hypervisor。
- 只暴露一组固定的、经过白名单筛选的设备。
- 把运行中的虚拟机捕获为不可变的产物，使其可以在新的进程中恢复，而不必序列化原生宿主句柄。
- 每个微虚拟机只运行一个工作负载。
- 用不可变镜像层、私有的可写暂存空间以及可选的实时宿主共享来组装工作负载文件系统。
- 将工作负载策略和宿主资源挂载保持在宿主控制之下。
